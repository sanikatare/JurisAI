# FinSight AI — Phase 4 Architecture Specification

## 1. Overview
Phase 4 builds the Generative AI, Retrieval-Augmented Generation (RAG), Investigation Intelligence, and Decision Support layer on top of the Phase 2 data pipeline and Phase 3 machine learning foundation.

**Fundamental Operational Principle**: The LLM is **never** permitted to make autonomous fraud or enforcement decisions (e.g. "freeze card", "block account", "definitely fraudulent"). All computed metrics (ML risk scores, calibrated probabilities, anomaly scores, graph degree/risk, SHAP feature importances) are deterministically generated by upstream engines. The GenAI layer synthesizes structured evidence, answers analyst questions, explains risk indicators, retrieves policy guidance, and generates auditable case reports.

## 3. Component Details & Security Boundaries

### 3.1 Deterministic Evidence Collector (`src/genai/evidence.py`)
Fetches all case evidence before any LLM interaction:
- **Transaction Evidence**: Amount, time, product category, device, email domain.
- **ML Risk Evidence**: Calibrated fraud probability, risk tier, decision threshold.
- **SHAP Evidence**: Top 5 feature attribution values derived via TreeSHAP/KernelSHAP.
- **Graph Evidence**: Degree, shared device count, shared email domain count, relational risk.
- **Anomaly Evidence**: Isolation Forest unsupervised novelty score.

### 3.2 RAG Knowledge Base (`src/genai/rag/`)
- **Knowledge Base**: Policy documents, AML rules, KYC guidelines, Investigation SOPs.
- **Chunking**: 300–500 token sliding windows with heading/section metadata preservation.
- **Hybrid Retrieval**: Combines Dense Vector Search (FAISS) with Lexical Search (BM25) via Reciprocal Rank Fusion.
- **Citations**: Assigns deterministic IDs (`[RAG-001]`, `[RAG-002]`).

### 3.3 Prompt & Guardrail Engine (`src/genai/guardrails.py`, `src/genai/prompts.py`)
- **Input Guardrails**: Prompt injection detection, input size limits, secret filtering.
- **Output Guardrails**: Citation verification, schema enforcement, forbidden decision keyword translation ("freeze" $\to$ "elevated risk warranting investigation").

### 3.4 Read-Only Data Analyst Agent (`src/genai/agents/data_analyst.py`)
- Executes **strict SELECT queries only** on PostgreSQL / SQLite view allowlists (`view_daily_transaction_summary`, `view_model_performance_summary`).
- Validates SQL syntax with AST parsing; rejects all DDL/DML (`INSERT`, `UPDATE`, `DELETE`, `DROP`).

## 5. Security & Isolation Model
1. **Secrets**: API keys stored in `.env` (never committed).
2. **Fallback Mode**: Offline Mock LLM Provider ensures 100% system operation even when cloud APIs are unreachable.
3. **Database Security**: Dedicated read-only role for SQL analytics.
