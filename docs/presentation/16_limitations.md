# Slide 16: System Limitations

## Documented Constraints
- **Anonymized Features**: Masked column names in IEEE-CIS dataset limit deep domain interpretability for certain V-variables.
- **Concept Drift Decay**: Model performance decays by ~3.5% PR-AUC over 6 months without retraining.
- **External LLM RTT**: Live LLM investigation latency depends on cloud API network RTT.
- **Decision-Support Scope**: Barred from taking autonomous legal or financial enforcement actions.
